# 도서 대여 관리 프로그램

콘솔(CLI)에서 동작하는 Java 도서 대여 관리 프로그램입니다. 회원가입과 로그인을 거쳐 도서를 검색하고 대여·반납할 수 있으며, 운영자는 도서를 등록·수정·삭제하고 전체 대여 현황을 관리할 수 있습니다. 모든 데이터는 CSV 파일로 저장되어 프로그램을 다시 실행해도 유지됩니다.

## 1. 프로젝트 소개

### 문제

도서를 여러 사람이 함께 빌려 보는 환경에서는 어떤 책이 지금 대여 중인지, 누가 언제 빌렸는지를 기억이나 메모에 의존해 관리하기 어렵습니다.

### 목표

- 회원별로 로그인하여 도서를 대여·반납하고, 자신의 대여 현황과 기록을 확인할 수 있게 한다.
- 운영자가 도서를 등록·수정·삭제하고 전체 대여 현황을 확인할 수 있게 한다.
- 데이터를 CSV 파일에 저장하여 프로그램을 종료한 뒤 다시 실행해도 그대로 불러온다.
- 잘못된 입력, 존재하지 않는 데이터, 손상된 파일에도 프로그램이 멈추지 않고 안내 메시지를 출력한다.

## 2. 주요 기능

### 시작 메뉴

| 기능 | 설명 |
|---|---|
| 로그인 | id와 비밀번호로 로그인합니다. 운영자는 운영자 메뉴, 일반 회원은 회원 메뉴로 이동합니다. |
| 회원가입 | 새 id와 비밀번호로 가입합니다. id는 영문과 숫자만 사용할 수 있고 이미 있는 id는 사용할 수 없으며, 비밀번호는 8자 이상이어야 합니다. |
| 종료 | 프로그램을 종료합니다. |

### 회원 메뉴

| 기능 | 설명 |
|---|---|
| 도서 목록 보기 | 전체 도서와 대여 가능 여부를 보여줍니다. |
| 도서 검색 | 제목의 일부로 도서를 검색합니다. |
| 도서 대여 | 도서 id를 입력해 대여합니다. 이미 대여 중인 도서는 빌릴 수 없습니다. |
| 도서 반납 | 도서 id를 입력해 반납합니다. 본인이 대여 중인 도서만 반납할 수 있습니다. |
| 내 대여 현황 | 아직 반납하지 않은 도서만 보여줍니다. |
| 내 대여 기록 | 반납한 도서를 포함한 전체 대여 기록을 보여줍니다. 이미 삭제된 도서도 대여 당시의 제목으로 표시됩니다. |

### 운영자 메뉴

| 기능 | 설명 |
|---|---|
| 도서 등록 | 제목과 저자를 입력해 도서를 등록합니다. 제목과 저자가 모두 같은 도서는 중복으로 등록할 수 없습니다. |
| 도서 목록 보기 / 도서 검색 | 회원 메뉴와 같으며, 대여 중인 도서는 빌린 회원의 id도 함께 보여줍니다. |
| 도서 정보 수정 | 제목과 저자를 수정합니다. 아무것도 입력하지 않고 Enter를 누르면 기존 값이 유지됩니다. |
| 도서 삭제 | 도서를 삭제합니다. 대여 중인 도서는 삭제할 수 없습니다. |
| 전체 대여 현황 | 모든 회원의 아직 반납되지 않은 대여를 보여줍니다. |
| 전체 대여 기록 | 반납된 것을 포함한 모든 대여 기록을 보여줍니다. 이미 삭제된 도서도 대여 당시의 제목으로 표시됩니다. |
| 회원 현황 | 가입한 회원 수와, 회원별로 현재 대여 중인 도서와 누적 대여 횟수를 보여줍니다. 비밀번호는 표시하지 않습니다. |

### 운영자 계정

| id | 비밀번호 |
|---|---|
| `admin` | `admin0000` |

운영자 계정은 코드에 고정되어 있어 별도의 가입 없이 바로 로그인할 수 있으며, 데이터 파일을 모두 지워도 항상 로그인할 수 있습니다.

## 3. 프로그램 구조

```
sju-java-project/
├── README.md
├── .gitignore                    GitHub에 올리지 않을 파일 목록 (데이터, 컴파일 결과물 등)
├── src/
│   ├── Main.java                 콘솔 메뉴와 사용자 입력 처리 (프로그램 시작점)
│   ├── model/                    데이터를 표현하는 클래스
│   │   ├── Book.java             도서 (id, 제목, 저자, 대여 여부)
│   │   ├── Member.java           회원 (id, 비밀번호, 운영자 여부)
│   │   └── Rental.java           대여 기록 (도서 id, 도서 제목, 회원 id, 대여일, 반납일, 반납 여부)
│   ├── service/                  기능(비즈니스 규칙)을 담당하는 클래스
│   │   ├── MemberService.java    회원가입, 로그인, 회원 목록 조회
│   │   ├── LibraryService.java   도서 등록·수정·삭제·검색, 대여·반납, 대여 현황·기록 조회
│   │   └── *Exception.java       규칙 위반 시 발생하는 예외 8종
│   └── io/                       파일 입출력
│       ├── CsvConvertible.java   CSV 한 줄로 저장될 수 있는 객체의 인터페이스
│       └── CsvStorage.java       CSV 파일 읽기·쓰기, 손상된 줄 처리
└── data/                         실행 중 생성되는 CSV 데이터 파일
```

### 클래스별 역할

| 패키지 | 클래스 | 역할 |
|---|---|---|
| (기본) | `Main` | 메뉴를 출력하고 입력을 받아 서비스 클래스를 호출하며, 예외를 받아 안내 메시지로 보여줍니다. |
| `model` | `Book`, `Member`, `Rental` | 데이터를 담는 클래스입니다. 필드는 `private`이고, 바뀌어야 하는 값만 메서드로 변경할 수 있습니다. |
| `service` | `MemberService` | 회원 정보를 `HashMap<String, Member>`로 관리하며 회원가입, 로그인, 회원 목록 조회를 처리합니다. |
| `service` | `LibraryService` | 도서와 대여 기록을 `ArrayList`로 관리하며 도서 관리, 대여·반납 규칙, 대여 현황·기록 조회를 처리합니다. |
| `service` | `DuplicateIdException` 외 7종 | 중복 id, 로그인 실패, 잘못된 입력, 비밀번호 조건 위반, 도서 중복, 존재하지 않는 도서, 대여 불가, 반납 대상 없음의 상황을 각각 나타냅니다. |
| `io` | `CsvConvertible` | `Book`, `Member`, `Rental`이 구현하는 인터페이스입니다. 이 덕분에 `CsvStorage.writeAll()` 하나로 세 종류의 데이터를 모두 저장합니다. |
| `io` | `CsvStorage` | CSV 파일을 읽고 쓰며, 파일 오류와 형식이 깨진 줄을 처리합니다. |

## 5. 실행 방법

> **모든 명령어는 저장소의 최상위 폴더에서 실행합니다.**
> `README.md`와 `src` 폴더가 바로 보이는 위치입니다. `src` 폴더나 `out` 폴더 안으로 들어가서 실행하지 않습니다.

### 1) 소스코드 내려받기

```bash
git clone https://github.com/wldn7601/sju-java-project.git
cd sju-java-project
```

`cd`로 들어간 이 폴더가 앞으로 모든 명령어를 실행할 위치입니다.

### 2) 실행 위치 확인

현재 위치에서 파일 목록을 확인합니다. (Windows 명령 프롬프트에서는 `dir`)

```bash
ls
# 결과 예시: README.md  src  ...  (data, out 등 다른 파일·폴더가 함께 보일 수 있음)
```

목록에 **`README.md` 파일과 `src` 폴더가 보이면** 올바른 위치입니다.

`data` 폴더와 `out` 폴더는 보일 수도 있고 안 보일 수도 있습니다. 처음 내려받았을 때는 없고, 프로그램을 컴파일하고 실행하면 자동으로 만들어지기 때문에 어느 쪽이든 문제없습니다.

### 3) 컴파일

```bash
javac -encoding UTF-8 -d out -sourcepath src src/Main.java
```

- `-encoding UTF-8`: 소스코드의 한글이 깨지지 않도록 합니다.
- `-d out`: 컴파일된 `.class` 파일을 현재 위치의 `out` 폴더에 만듭니다.
- `-sourcepath src`: `Main.java`가 사용하는 나머지 클래스도 `src`에서 찾아 함께 컴파일합니다.

컴파일이 끝나면 현재 위치에 `out` 폴더가 생깁니다.

### 4) 실행

컴파일한 위치에서 그대로 실행합니다.

```bash
java -cp out Main
```

프로그램은 데이터 파일을 **실행한 위치를 기준으로** `data/` 폴더에서 읽고 씁니다. 따라서 다른 위치에서 실행하면 기존 데이터를 찾지 못하고 그 위치에 새로운 `data` 폴더를 만들어 빈 상태로 시작합니다.

### 잘못된 위치에서 실행했을 때

| 증상 | 원인 |
|---|---|
| 컴파일 시 `file not found: src/Main.java` | `src` 폴더 안이나 다른 폴더에서 컴파일함 |
| 실행 시 `Could not find or load main class Main` | 컴파일하지 않았거나, `out` 폴더가 없는 위치에서 실행함 |
| 실행은 되지만 등록했던 회원·도서가 보이지 않음 | 처음과 다른 위치에서 실행해서 다른 `data` 폴더를 사용함 |

### 데이터 초기화

최상위 폴더에서 `data` 폴더의 CSV 파일을 지우면 처음 실행한 상태로 돌아갑니다.

```bash
rm data/*.csv
```

다시 실행하면 샘플 도서 5권과 운영자 계정 기록 파일이 자동으로 다시 만들어집니다.

## 7. 데이터 파일

모든 데이터는 `data/` 폴더에 UTF-8 CSV 파일로 저장됩니다. 데이터가 바뀔 때마다 바로 저장되고, 프로그램을 시작할 때 다시 불러옵니다.

| 파일 | 한 줄의 형식 | 내용 |
|---|---|---|
| `members.csv` | `id,비밀번호,운영자여부` | 가입한 일반 회원 |
| `books.csv` | `id,제목,저자,대여중여부` | 도서 목록 |
| `rentals.csv` | `도서id,도서제목,회원id,대여일,반납일,반납여부` | 대여 기록 (반납 전이면 반납일은 빈칸, 도서제목은 대여 당시의 제목) |
| `admin.csv` | `id,비밀번호,운영자여부` | 운영자 계정 기록 (참고용, 로그인은 코드의 상수로 처리) |

- 제목처럼 쉼표가 들어간 값은 따옴표로 감싸 저장합니다. 예: `3,"총, 균, 쇠",재레드 다이아몬드,false`
- 파일이나 `data` 폴더가 없으면 빈 상태로 시작하고, 저장할 때 자동으로 만듭니다.
- `books.csv`가 없을 때는 샘플 도서 5권을 자동으로 등록합니다.
- 형식이 깨진 줄은 경고를 출력하고 건너뛰며, 나머지 데이터는 정상적으로 불러옵니다.

## 8. 테스트 기록

### 정상 동작

| 상황 | 입력 | 결과 |
|---|---|---|
| 회원가입 | id `kim`, 비밀번호 `kim12345` | `회원가입이 완료되었습니다. 로그인해주세요.` |
| 일반 회원 로그인 | `kim` / `kim12345` | `kim님 환영합니다.` 후 회원 메뉴 표시 |
| 운영자 로그인 | `admin` / `admin0000` | `admin님 환영합니다.` 후 운영자 메뉴 표시 |
| 도서 등록 | 제목 `소년이 온다`, 저자 `한강` | `등록되었습니다. (도서 id: 6)` |
| 도서 검색 | `왕자` | `[1] 어린 왕자 / 저자: 생텍쥐페리 (대여가능)` |
| 운영자 도서 목록 | `kim`이 2번 도서 대여 중 | `[2] 데미안 / 저자: 헤르만 헤세 (대여중: kim)` |
| 삭제된 도서의 대여 기록 | 반납된 도서를 삭제한 뒤 전체 대여 기록 확인 | `[6] 소년이 온다 (삭제된 도서) / 회원 id: kim / ...` |
| 도서 수정 | 새 제목에 Enter, 새 저자 입력 | 제목은 유지되고 저자만 바뀜 |
| 도서 대여 | 도서 id `2` | `대여가 완료되었습니다.` |
| 도서 반납 | 도서 id `2` | `반납이 완료되었습니다.` |
| 회원 현황 (운영자) | `kim`이 2권 대여 중, 누적 3회 | `kim / 대여 중 2권 / 누적 대여 3회` 아래에 `[2] 데미안`, `[1] 어린 왕자`가 한 줄씩 표시됨 |
| 쉼표가 들어간 제목 | `총, 균, 쇠` 저장 후 재실행 | 제목이 그대로 다시 불러와짐 |
| 데이터 유지 | 대여 후 종료하고 재실행 | 대여 현황이 그대로 남아 있음 |
| 데이터 초기화 | `rm data/*.csv` 후 실행 | `샘플 도서 5권을 등록했습니다.` |
